# 4. Prompt Templates

## What
Covers creating, using, saving, and loading prompt templates, plus building Streamlit UIs around them.

## Tech
- `langchain-core` — `PromptTemplate`, `load_prompt`
- `langchain-groq` — Groq LLM for fast inference
- `streamlit` — web UI
- `python-dotenv` — API key management

## Files

### `prompt_generator.py`
- **What**: Creates a `PromptTemplate` for research paper summarization and saves it to `template.json`.
- **How**: Defines a template with `{paper_input}`, `{style_input}`, `{length_input}` placeholders, then calls `.save()`.
- **When**: Run this once to generate the `template.json` file used by `loadingPrompt.py`.

### `template.json`
- **What**: Serialized prompt template stored as JSON.
- **How**: Auto-generated by `prompt_generator.py` via `PromptTemplate.save()`.
- **When**: Loaded at runtime by `loadingPrompt.py` using `load_prompt()`.

### `prompt_ui.py`
- **What**: Minimal Streamlit app — user types a free-form prompt, model responds.
- **How**: `st.text_input` → `llm.invoke(user_input)` → `st.write(response)`.
- **When**: Use as the simplest possible UI wrapper around an LLM.

### `prompt_ui2.py`
- **What**: Streamlit app with dropdowns for paper, style, and length; uses an inline `PromptTemplate`.
- **How**: Builds the template in code, fills it with `template.invoke({...})`, sends to Groq.
- **When**: Use when you want a structured UI with a prompt template defined in the same file.

### `loadingPrompt.py`
- **What**: Same UI as `prompt_ui2.py` but loads the template from `template.json` instead of defining it inline.
- **How**: `load_prompt("template.json")` restores the saved template; rest of the flow is identical.
- **When**: Use to demonstrate separation of prompt definition from application logic.

## Key Concepts
- `PromptTemplate` — reusable template with named `{placeholders}`
- `template.invoke({...})` — fills placeholders and returns a formatted prompt
- `template.save()` / `load_prompt()` — serialize and deserialize templates
- `validate_template=True` — checks that all variables are present at definition time
